🎯 FocusTrack – Memory Game

FocusTrack is a simple memory game inspired by the classic Simon Game.
I built this project using HTML, CSS, and JavaScript to practice and improve my frontend development skills.
This is a mini project made as part of my learning journey.

📌 About the Project

The game shows a sequence of colors, and the player has to remember and repeat the same sequence by clicking the tiles.
With every level, the sequence gets longer and the game becomes more challenging.
While building this project, I learned a lot about how JavaScript works and how logic is applied in real projects.

✨ Features

Color sequence memory game
Level system
Session-based high score
Smooth animations and visual effects
Pastel themed UI
Sparkle cursor effect
Decorative animated elements
Starts with keyboard input

🎮 How to Play

Press any key to start the game
Watch the color that flashes
Click the same color
Each level adds one more color
Try to remember the full sequence
Game ends if you click the wrong tile
